# Black Friday Explosiva — funil de vendas

Site estático (HTML/CSS/JS), sem etapa de build. Checkout, upsell e área de membros ficam na Ticto.

- Páginas: `index.html` (com vídeo), `promessa.html` (sem vídeo), `upsell.html`, `downsell.html`, `comunidade.html`, `obrigado.html`, `termos.html`, `privacidade.html`
- Configuração (preços, links da Ticto, textos): `assets/config.js`
- Ver o que falta preencher: abra qualquer página com `?revisao=1`
- Rodar local: `python -m http.server 5180` nesta pasta e abrir http://localhost:5180
- Publicar: Vercel/Netlify/GitHub Pages apontando para a raiz deste repositório
